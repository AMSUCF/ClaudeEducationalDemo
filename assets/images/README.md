# Assets Directory

## Images

### the-diamond-age.png

**Required:** Place the Diamond Age book cover image here.

- **Filename:** `the-diamond-age.png`
- **Recommended size:** 250-400px width
- **Format:** PNG (preferred) or JPG
- **Description:** Cover of Neal Stephenson's "The Diamond Age: Or, A Young Lady's Illustrated Primer"

This image will be displayed on the Resources page with a retro-styled border effect and will float left with text wrapping around it.

If the image is not present, the page will show a broken image icon until the file is added.
